# Corpus

30 deterministic programs, `Pnn_Name/` each building `Corpus.Pnn.dll` with `Corpus.Program.Run(string)`.
Each folder has `inputs.json` (8 public inputs) and `expected.json` (generated by `Xeno.Corpus.Capture`; never hand-edit).
Held-out inputs live outside the repo.

Regenerate: `dotnet corpus/Xeno.Corpus.Capture/bin/Debug/net8.0/Xeno.Corpus.Capture.dll <Corpus.Pnn.dll> <inputs.json> <expected.json>`.
`dotnet test` rebuilds the programs and checks expected.json against a fresh capture plus run-twice determinism.
